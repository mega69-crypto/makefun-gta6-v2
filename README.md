Solara Bay is a 2D top-down open-world crime game in plain HTML, CSS and JavaScript: explore a coastal city on foot and by car, steal cars, outrun the police under a 1 to 5 star wanted level, run four story missions for Vic, and take the Big Score.

## Run it

```sh
python3 -m http.server 8080 --directory game
```

Then open http://localhost:8080 in a desktop browser. No build step and no network needed: every file the game loads sits under game/.
